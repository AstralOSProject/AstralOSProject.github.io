codename: miatoll

Special boot modes

  • Recovery: With the device powered off, hold Volume Up + Power. Then select recovery from bootloader using the hardware keys.
  • Fastboot: With the device powered off, hold Volume Down + Power.

Installation

  1. Unlock the bootloader. Enable Developer options (tap MIUI version 7 times), then enable OEM unlocking. Use Xiaomi's Mi Unlock tool on a PC — the account waiting period is typically 168 hours. Unlocking wipes the device.

  2. Download the files. Save the AstralOS zip from the Downloads section above, and keep the matching recovery.img from the release assets next to it on your PC.

  3. Boot to fastboot. Power off the phone, then hold Volume Down + Power. Connect it to your PC.

  4. Flash the AstralOS recovery:

    fastboot flash recovery recovery.img

  5. Boot to recovery. Hold Volume Up + Power until the recovery appears, then perform a Factory reset.

  6. Sideload the zip. In recovery choose Apply update → ADB sideload, then run on your PC:

    adb -d sideload AstralOS-1.0-OFFICIAL-miatoll.zip

  7. Reboot. Select Reboot system now. The first boot takes a few minutes.

Updating to a newer build

  • Sideload the new zip from recovery exactly like step 5–6 above — no data wipe is needed for same-version updates.
  • If anything misbehaves after an update, wipe cache/dalvik in recovery first — your data stays intact.
