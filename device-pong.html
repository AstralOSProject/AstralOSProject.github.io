Special boot modes

  • Recovery: With the device powered off, hold Volume Up + Power.
  • Bootloader/Fastboot: With the device powered off, hold Volume Down + Power.

Known quirks

  • Device integrity: Play Integrity checks may fail on custom ROMs.

Installation

  1. Confirm compatibility. The models listed for this device are A065 and AIN065. Check the model in Settings before proceeding.

  2. Review device requirements. Read the upstream installation guide for its device-specific firmware and bootloader requirements. Those steps install LineageOS, not AstralOS.

  3. Wait for AstralOS files. This page does not have an AstralOS package or flashing steps to use yet. Do not flash the upstream LineageOS files as AstralOS.

Updating to a newer build

  • AstralOS update packages and update steps are not published for this device yet. Use the release page only when a matching package is listed.
