Special boot modes

  • Recovery: With the device powered off, hold Volume Up + Home + Power. Release the buttons when the recovery screen appears.
  • Download mode: With the device powered off, hold Volume Down + Home + Power.

Known quirks

  • IMS: Calling features such as VoLTE can depend on your carrier.
  • Device integrity: Play Integrity checks may fail on custom ROMs.

Installation

  1. Confirm compatibility. This page covers the Exynos models SM-G930F, SM-G930FD, SM-G930S, SM-G930K, SM-G930L, and SM-G930W8. Other Galaxy S7 variants use different device support.

  2. Review device requirements. Read the upstream installation guide for its recovery and boot mode details. It describes LineageOS installation and is not an AstralOS flashing guide.

  3. Wait for AstralOS files. This page does not have an AstralOS package or flashing steps to use yet. Do not flash the upstream LineageOS files as AstralOS.

Updating to a newer build

  • AstralOS update packages and update steps are not published for this device yet. Use the release page only when a matching package is listed.
